# IPD 敏捷数字化工具箱

外层 IPD、内层敏捷的本地化数字项目管理工具箱：从商业目标 → 产品能力 → 需求 → 迭代/看板 → 测试与缺陷 → 变更与风险 → 证据 → DCP 准入 → 跨职能准备度 → 阶段决策，全程可正/反向追溯、有守卫、有审计，指标由业务数据自动计算并可下钻。

第一版「全流程能力验证」（规划阶段0～4）已于 2026-08 通过 M5 验收；此后按"单人本机个人工具箱"定位持续演进：个人化扩展（我的一天/路标/汇报/MCP）→ 八项 PM 功能优化 → 四项领域深化（基线管理/关键路径/风险深化/复盘与组织资产）。

## 功能总览

侧栏导航为两级结构：**我的一天**与**项目驾驶舱**为高频一级入口，其余按 IPD 业务域分五组（一次只展开一组，当前页所在组自动展开）。

### 核心机制

- **统一 WorkItem 模型**：能力/需求/故事/任务/缺陷/风险/变更 7 类型单表承载，统一详情抽屉全站复用（描述支持 Markdown + 粘贴截图直传）；
- **状态机 + 5 条守卫**：Ready 承诺、Verification 证据、Accepted 验收、缺陷复测、变更影响分析，回退强制填理由；批量操作支持 dry-run 预检"哪些会被拦、为什么"；
- **10 种追溯关系**：正反向建链/断链与全链查询；断链主动预警（需求无测试覆盖/无实现链、能力未分解）；
- **基线与偏差**：DCP 通过即固化范围基线（只增不删），承诺 vs 现状的蔓延/偏差/漂移可量化——变更管理从流程闭环升级为偏差管理；
- **证据与决策**：文件证据 SHA-256 摘要入库；Decision 只增不改且修订自动串链（prevDecisionId），DCP 决策固化准备度快照、结项时全链可回放；
- **排期推演**：基于 depends_on/blocks 依赖与估算的 CPM 关键路径（ES/EF/浮动/关键链，未估算项显式警示）；
- **风险量化**：概率×影响敞口分级（高≥15/中≥8）、应对策略四分类、处置措施一键任务化（affects 链）、敞口总量进指标趋势；
- **全程审计**：状态、责任人、决策、基线、结项检查自动落 AuditEvent；
- **时点回放**：状态时间线无旁路写入 → 任意历史日期的项目状态可精确重建（时光机），复盘从"凭记忆"变"可回放"；
- **指标只读**：驾驶舱与效能指标全部由业务数据自动计算，无人工填报入口，无个人绩效口径；
- **全局快捷键**：`/` 聚焦搜索、`n` 快速新建、`g+字母` 跳页、`?` 速查表。

## 技术栈

| 层 | 选型 |
|---|---|
| 前端 | Vue 3 + TypeScript + Vite + Element Plus + ECharts + Pinia |
| 后端 | Spring Boot 3.2 + Java 21 + MyBatis-Plus + Flyway |
| 数据库 | MySQL 8.4（Docker） |
| 认证 | JWT + 简单 RBAC（7 角色） |
| 证据 | 本地文件目录 + SHA-256 摘要（元数据入库） |
| AI 对接 | MCP Server（Node/TypeScript，封装 REST API 供 Claude Code 等使用） |

> 注意：本机默认 `java` 为 1.8，构建后端须用 JDK 21：
> `export JAVA_HOME=/Library/Java/JavaVirtualMachines/temurin-21.jdk/Contents/Home`

## 快速启动

```bash
# 1. 起数据库
cd deploy && docker compose up -d

# 2. 起后端（JDK 21）
cd ../backend
export JAVA_HOME=/Library/Java/JavaVirtualMachines/temurin-21.jdk/Contents/Home
mvn -DskipTests package
java -jar target/ipd-toolbox.jar          # http://localhost:8080

# 3. 起前端
cd ../frontend
npm install
npm run dev                                # http://localhost:5173
```

演示账号：**admin / admin123**（兼全部角色）。
接口文档：http://localhost:8080/swagger-ui.html

### e2e 回归保护网

```bash
./deploy/e2e_ui.sh               # 三条关键动线，约 1 分钟
```

一条命令起完整环境（**独立库 `ipd_toolbox_e2e` + 后端 18080 + 前端 15173**）跑 Playwright，跑完自动清理——你日常使用的实例（`ipd_toolbox` / 8080 / 5173）全程不受影响，主库不会被写入任何测试数据。

护的三条动线：①登录 →「我的一天」聚合渲染；②建需求 → 拉入迭代 → 抽屉流转（含两处 Ready 守卫拦截断言）；③铺 DCP 条件模板 → 传证据 → 红线拦截 → 有条件通过 → 决策落库 + 基线自动固化。原则是**只护动线不护像素**，不做截图比对。

常用参数：`--keep` 跑完保留环境、`--headed` 开窗口看、`03` 只跑第三条。

### 备份与恢复

```bash
./deploy/backup.sh                     # mysqldump + 证据目录打包，并滚动清理旧备份
./deploy/restore.sh <备份目录>          # 已实测：删库恢复后数据与 SQL 视图完整还原
./deploy/restore_drill.sh              # 每月恢复演练：恢复到临时库核对后丢弃，不碰主库
```

保留策略：近 14 天全量 + 更早的每周留 1 份。每日自动备份（03:10）安装两行：

```bash
cp deploy/com.ipd.toolbox.backup.plist ~/Library/LaunchAgents/ && launchctl load ~/Library/LaunchAgents/com.ipd.toolbox.backup.plist
```

## AI 对接（MCP Server）

[mcp/](./mcp/) 将工具箱 REST API 封装为 MCP tools，供 Claude Code 用自然语言操作：拆会议纪要为需求任务（默认 dry-run 预览）、查项目状态、查基线偏差与关键路径、检索经验教训、汇编 DCP 评审材料等。读工具 12 个、写工具 4 个；DCP 评审、变更审批等决策类动作刻意不开放给 AI，留在 UI 由人完成。

安装注册见 [mcp/README.md](./mcp/README.md)，使用约定见 [docs/06-AI操作手册.md](./docs/06-AI操作手册.md)。

## 项目状态与后续

- **第一版（规划阶段0～4）已完成**：全流程闭环、§15 验收清单 21 项全部通过，端到端剧本可一键连续演示，备份恢复实测通过。
- **个人化扩展（2026-08）**：「我的一天」跨项目工作台、路标图、Markdown+截图录入、批量操作、全局快捷键、汇报输出（状态报告/DCP 决策包，打印即 PDF）、MCP Server 对接 Claude Code。
- **八项 PM 功能优化（2026-08）**：责任人显示名、项目周报自动生成、DCP 条件模板库、追溯完整性预警、看板 WIP 限制、批量预检、WSJF 评分、迭代复盘页。
- **四项领域深化（2026-08）**：范围基线管理（DCP 咬合）、关键路径推演（CPM）、风险管理深化（矩阵/敞口/任务化）、复盘与组织资产（决策链回放/经验教训库/风险模式库/结项流程）——工具从"记录系统"升级为"偏差管理与组织资产系统"。
- **时光机（2026-08）**：单点回溯（任意日期的状态重建）+ A/B 双时点对比（期间新增/完成/推进与 KPI 变化），侧栏导航同步整合为两级分组。
- **上车准备（2026-08）**：三条关键动线的 Playwright e2e 保护网（独立库隔离，不碰主库）；工具箱自身建档为 `TOOLBOX` 项目，用它自己的 improvement 闭环承载摩擦日志。
- **后续方向**：进入六周 dogfooding——只用它、只修摩擦、冻结新功能，之后的建设主题由摩擦日志的分类计数决定，不预先规划（规划§17，落地计划见 [docs/07](./docs/07-演进落地计划.md)）。阶段6（组合与经营管理）不提前建设。
