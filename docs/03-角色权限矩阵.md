# 角色与权限矩阵（阶段0 · T004）

> 驱动简单 RBAC（T105）与关键操作的授权校验（变更审批 T405、DCP 决策 T505）。

## 角色

| 角色 code | 名称 | 职责 |
|---|---|---|
| ADMIN | 系统管理员 | 用户/角色、备份恢复、全部操作 |
| PM | 项目经理 | 项目/版本/阶段/DCP 定义、Sprint 计划 |
| PO | 产品负责人 | 能力/需求、能力验收 |
| DEV | 开发 | 任务开发、缺陷修复、提交增量 |
| QA | 测试 | 用例/执行、缺陷创建、证据上传 |
| QUALITY | 质量负责人 | 风险登记、DCP 条件维护、发起评审 |
| REVIEWER | 评审角色 | 变更审批、DCP 正式决策（授权决策人） |

一个用户可兼多角色。第一版演示账号：`admin` 兼全部角色。
