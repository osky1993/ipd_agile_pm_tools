## 第一轮使用反馈与下一阶段优先级（T708）

**已贯通的核心闭环**：商业目标 → 产品能力 → 需求 → 迭代/看板 → 测试与缺陷 → 变更与风险 → 证据 → DCP 准入 → 跨职能准备度 → 阶段决策，且全程可正/反向追溯、有守卫、有审计、指标自动计算并可下钻。

**观察到的下一步优化点（按规划§17，由真实瓶颈决定）**：
1. **测试执行数据的时序去重**：同一用例多次执行时，指标取最新一次结果——符合预期，但演示前应清理历史噪声数据（建议 e2e 用独立库）。
2. **驾驶舱趋势**：当前为快照值，缺陷流入/关闭趋势、条件满足趋势（规划§7.4）需引入时间序列（E7 可迭代增强）。
3. **权限数据范围**：当前 RBAC 为操作级，尚未做数据范围（项目级）隔离——承载第二个真实项目前需补（阶段5 T9.2）。
4. **附件预览**：证据支持下载，图片/PDF 内联预览可增强。

**暂不建设**（规划§12.2）：微服务、消息队列、ES、数仓、BPMN、多租户、移动端、报表设计器、AI 等——均不直接帮助第一版闭环验证。

**下一阶段方向判断**：第一版已稳定承载单项目全流程。是否进入阶段5（工程化）取决于是否要承载第二个真实项目；是否深化 PLM/ALM/ERP 集成取决于真实瓶颈出现在配置/追溯/供应哪一侧。
